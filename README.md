## gspdfr-outline

This offline tool saves the Table of Contents outline generated by Google Scholar PDF Reader (v0.3.8) scripts onto the pdf. Use through the web UI or by CLI (headless). 

### Web UI

1. Serve this folder with any static server (e.g. `python -m http.server`, `npx serve`).
2. Open `index.html`, upload PDF, and download the output `[input]-outlined.pdf`.
   - On "Failed to embed outline into PDF", try re-exporting a pdf using a native application or reprocess it with Ghostscript (`gs -o in-after.pdf -sDEVICE=pdfwrite -dCompatibilityLevel=2.0 input.pdf`).
   - Primarily works on Chromium-based browsers, though Firefox should be okay. 

### CLI

```bash
npm install
node cli.js input.pdf [output.pdf]
```
